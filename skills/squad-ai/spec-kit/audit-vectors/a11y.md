# Vetor: A11y — acessibilidade WCAG 2.2 AA (escopo: skills com UI)

## Escopo — quando aplica
**So** quando a wave gera **interface**: HTML, JSX/TSX, PPTX, ou PDF com UI/forms.
Para tudo o mais (skills de doc, scripts, APIs sem front, pipelines):

```
A11Y @ W<n>:  N/A — fora de escopo (a wave nao gera UI)
```

Nao invente achados de a11y onde nao ha UI. `N/A` e um resultado valido e esperado.

## Checklist WCAG 2.2 nivel AA (itens verificaveis por inspecao de codigo)

| Criterio WCAG | O que checar no codigo | Como (grep/inspecao) |
|---|---|---|
| 1.1.1 Texto alternativo | toda `<img>` tem `alt`; icone informativo tem rotulo | `grep "<img" sem `alt=` -> achado |
| 1.4.3 Contraste (minimo) | texto >= 4.5:1; texto grande >= 3:1 | inspecionar cores no CSS/tema |
| 1.4.11 Contraste nao-textual | borda de input/botao/foco >= 3:1 | inspecionar tokens de cor |
| 2.1.1 Teclado | toda acao alcancavel por teclado; sem `onClick` em `<div>` sem `role`+`tabindex` | grep `onClick` em elemento nao-focavel |
| 2.4.3 Ordem de foco | ordem do DOM = ordem logica; sem `tabindex > 0` | grep `tabindex="[1-9]` -> achado |
| 2.4.7 Foco visivel | `:focus-visible` nao removido (`outline:none` sem alternativa) | grep `outline:\s*none` |
| 2.5.8 Alvo (minimo) | alvo de toque >= 24x24 CSS px | inspecionar tamanho de botao/link |
| 3.3.2 Rotulos | todo input tem `<label>`/`aria-label`/`aria-labelledby` | grep `<input` sem label associado |
| 4.1.2 Nome/Funcao/Valor | componente custom expoe `role`/`aria-*` corretos | inspecionar ARIA em widgets |
| 4.1.3 Mensagens de status | feedback assincrono em `aria-live`/`role=status` | grep de toast/alert sem `aria-live` |

> WCAG 2.2 acrescentou (sobre 2.1): 2.4.11 foco nao-ocluso, 2.5.7 arrastar, 2.5.8 alvo
> minimo, 3.3.7 entrada redundante, 3.3.8 auth acessivel. Cheque os aplicaveis a UI gerada.

## Saida (formato)
```
A11Y @ W<n>
1.1.1 alt-text    🔴  components/Card.tsx:14  <img> sem alt
3.3.2 labels      🟡  forms/Login.tsx:30      input email sem <label> (tem placeholder)
2.4.7 foco        🔵  globals.css:5           outline:none — confirmar :focus-visible alternativo
veredito:         NOT-GREEN (1x 🔴)
```

## Severidade
- 🔴 barreira que impede uso por tecnologia assistiva (sem alt, sem teclado, sem label) → bloqueante.
- 🟡 degradacao (contraste no limite, foco fraco) → proxima wave.
- 🔵 a confirmar por inspecao manual/ferramenta → observacao.

## Reuso
Delega a `especialista-frontend` (UI/acessibilidade) quando existir. Ferramentas externas
(axe-core, Lighthouse, pa11y) complementam — mas o vetor opera por **inspecao de codigo**
no loop, sem depender de browser no CI.

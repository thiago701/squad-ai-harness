## 2. Perfil Real de Consumo e Hardware da Estação Auditada

As medições diretas na máquina de desenvolvimento revelaram uma discrepância crítica entre o hardware físico real e o que o `SquadAI Harness v0.8.0` enxerga:

- **CPU Física:** `Intel(R) Core(TM) i7-10510U CPU @ 1.80GHz` (`4` núcleos físicos, `8` processadores lógicos, clock base `2304 MHz`, RAM física `16,2 GiB`).
- **GPU Dedicada (dGPU):** `NVIDIA GeForce MX110` (`2048 MiB` VRAM total, `37 MiB` em uso pelo OS, arquitetura Maxwell `GM108` / Compute Capability `sm_50`, `2` Multiprocessadores SM, `1024` max threads/block, Driver WDDM `451.67` / CUDA Driver API `11.0` via `C:\Windows\System32\nvcuda.dll`).
- **GPU Integrada (iGPU):** `Intel(R) UHD Graphics` (`1024 MiB` AdapterRAM).
- **Diagnóstico de `.\squad-harness.exe compute` (Baseline Go atual):** Reportou `"gpu_vendor": "NONE_CPU_ONLY", "has_dgpu": false, "has_igpu": false, "total_vram_mb": 0, "physical_cores": 8` — falhando em detectar tanto a `GeForce MX110` quanto a contagem real de núcleos físicos (`4` vs `8` lógicos).

## 4. Síntese da Auditoria Arquitetural

1. **O que funciona muito bem hoje em Go 1.24.3 (Não Tocar):**
   - O binário único `squad-harness.exe` tem inicialização instantânea (`< 5 ms`), zero dependências externas em `go.mod`, excelente portabilidade Windows 11 PowerShell-first, scanner de segredos rápido (`secretscan`) e governança determinística (`gopurity.go`, `delivery.go`).
2. **Onde residem os verdadeiros gargalos e deficiências cognitivas:**
   - **Deficiências de Inteligência Preditiva e Estrutural (`GAP-03`, `GAP-04`, `GAP-05`, `GAP-06`, `GAP-07`, `GAP-08`):** O uso de contadores inteiros estáticos (`count >= 3`), BFS de 2 saltos sem pesos nem timestamps, léxico fixo de 8 eixos, 9 especialistas em `passDefault`, `"blast_radius": 42` hardcoded e um EWMA autorrealizável que grava a própria estimativa limitam severamente a precisão analítica da SquadAI.
   - **Gargalo de IPC Go ↔ Rust (`GAP-02`):** Invocar binários auxiliares via `CreateProcessW` a cada chamada adiciona `~45–160 ms` de latência fixa, anulando qualquer ganho de microssegundos. O uso de um servidor MCP persistente (`Keep-Alive` + arena binária `.kdg`) é pré-requisito obrigatório para qualquer coprocessador Rust/CUDA.
   - **Realidade Física da GPU Local (`GAP-01`, `GAP-09`):** A estação possui uma `NVIDIA GeForce MX110` (`2048 MiB` VRAM, Maxwell `sm_50`, 2 SMs). Nessa classe de GPU de entrada, transferências PCIe por chamada (`HtoD` + `DtoH`) dominam cargas pequenas; a GPU só entrega ganho líquido quando **os dados/pesos permanecem residentes em VRAM** ou quando o volume computacional por chamada é elevado (`Large`/`XL`).
